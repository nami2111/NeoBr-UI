# NeoBr-UI

A high-performance, accessible, and stunningly beautiful Neo-Brutalist component library for modern web development.

NeoBr-UI combines the raw, industrial aesthetic of Neo-Brutalism with high-end animations, accessibility best practices, and a developer experience focused on productivity.

## Core Principles

- **Bold Aesthetics**: Vibrant colors, heavy borders, and sharp shadows.
- **High-End Motion**: Snappy, fluid transitions powered by Svelte's native animation engine.
- **Accessibility First**: Fully compliant ARIA patterns and keyboard navigation.
- **Premium Feel**: Not just another MVP; every component is polished for production use.

## Repository Structure

- `packages/svelte`: The core Svelte 5 component library.
- `apps/docs`: The official documentation and showcase site.

## Quick Start (Documentation)

If you want to play with the components locally:

```bash
pnpm install
pnpm --filter docs dev
```
