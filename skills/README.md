# NeoBr-UI Skills

These are distributable skills for people using `@neobr/svelte` in their own apps.
They are not local repo agent instructions.

## Install

Install all NeoBr-UI skills:

```bash
npx skills add nami2111/NeoBr-UI
```

## Skills

- `neobr-ui-builder`: build Svelte 5 UI with NeoBr-UI components and idioms.
- `neobr-ui-theming`: install NeoBr-UI and customize Tailwind CSS v4 design tokens.

These folders follow the `SKILL.md` format used by Skills.sh and compatible assistants.
